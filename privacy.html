Privacy Policy: ADHENGANE Uploader

Last updated: 26 November 2026

ADHENGANE Uploader ("the tool") is a personal desktop script. Its only user is the owner of the EXPLAIN HUB YouTube channel, who uses it to upload and schedule their own videos. This policy explains what the tool does with Google user data.

Data the tool accesses

The tool signs in with Google OAuth and asks for two YouTube Data API scopes:

  • youtube.upload, to upload videos to the owner's channel and set their title, description, tags and publish time;
  • youtube.readonly, to read the channel name and the status of videos the tool uploaded.

It does not access any other Google data, and it does not access other people's channels or data.

How the data is used and stored

The OAuth sign-in token is stored only on the owner's own computer, in a private folder, and is used only to make the API calls above. Video files, titles and descriptions are created by the owner. The tool keeps a local log of uploads (date, video ID, title).

Sharing

The tool does not sell, share or transfer any Google user data to anyone. Nothing is sent anywhere except to YouTube itself through the official API. The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions, or by deleting the local token file. YouTube's own data handling is described in the Google Privacy Policy, and use of YouTube is subject to the YouTube Terms of Service.
