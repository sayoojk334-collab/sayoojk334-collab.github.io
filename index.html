ADHENGANE Uploader

A private publishing tool for the EXPLAIN HUB YouTube channel.

ADHENGANE Uploader is a small desktop script that the owner of the EXPLAIN HUB YouTube channel uses to upload and schedule their own original Malayalam explainer Shorts.

It uses the YouTube Data API v3 to:

  • upload a finished video to the owner's own channel;
  • set its title, description, tags and scheduled publish time;
  • read back the upload status of those videos.

The tool is not offered to the public and has no other users. It does not read, collect or analyse anyone else's data.
